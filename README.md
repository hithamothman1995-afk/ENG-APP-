# مواقف: تطبيق تعلّم الإنجليزي للمتحدثين بالعربية

تطبيق ويب للجوال (PWA) يعلّم الإنجليزي بمنهج المواقف: مستويات ← كلاسات ← دروس.

## التشغيل على جهازك

1. ثبّت [Node.js](https://nodejs.org) (إصدار 22 أو أحدث).
2. افتح الطرفية (Terminal) داخل مجلد المشروع واكتب:
   ```
   npm install
   npm run dev
   ```
3. افتح الرابط الذي يظهر (مثل `http://localhost:5173`) في المتصفح.

### فتحه على جوالك
- اجعل الجوال والكمبيوتر على نفس شبكة الواي فاي.
- عند `npm run dev` يظهر سطر `Network: http://192.168.x.x:5173`. افتح هذا الرابط في متصفح الجوال.

## أوامر مفيدة
- `npm test`: تشغيل الاختبارات.
- `npm run build`: بناء نسخة النشر في مجلد `dist`.

## إضافة كلاس جديد
1. أنشئ ملفًا في `content/classes/` (انسخ `pharmacy.json` وغيّر `id` والعناوين).
2. تأكد أن الكلاس مذكور في `content/levels.json` بنفس `id`.
الكلاس يُفتح تلقائيًا عندما يكون له ملف محتوى.

## الخطوط
الخطوط محفوظة داخل التطبيق في `public/fonts` حتى تعمل بدون إنترنت:
- **IBM Plex Sans Arabic** للنصوص (عربي وإنجليزي).
- **Readex Pro** للعناوين والأرقام.
